## 🎯 Core Value Proposition & Pain Point

> **"Extract Any Skill from skills.sh or GitHub. Paste Directly into ChatGPT, Claude.ai, Gemini, DeepSeek, or Your Favorite Coding IDE."**

Most skills are locked behind terminal CLI commands (`npx skills add`) and only work inside specific IDE extensions (Cursor, Claude Code). **skills.sh Extractor** compiles any multi-file skill into a single self-contained prompt with inlined scripts and embedded docs so you can use it anywhere.
