Why This Exists: Freedom from CLI & IDE Silos

Most skills.sh skills require running npx skills add inside a terminal and only work inside specific IDE extensions. With the Extractor, any skill is compiled into a single, self-contained prompt with inlined scripts and embedded docs. Copy and paste it anywhere:

ChatGPT (GPT-4o) Claude.ai Projects Gemini Web DeepSeek Cursor IDE Windsurf Claude Code Antigravity
skills.sh Extractor is a client-side WebAssembly application that compiles multi-file AI capability skills into single-file, self-contained playbooks. It enables developers to extract any skills.sh or GitHub skill repository and copy-paste it directly into ChatGPT, Claude.ai, Gemini, DeepSeek, Cursor, Windsurf, and Antigravity with zero server dependencies and zero code leakage.

The Core Problem

          
Why We Built the WebAssembly Extractor

          
Skills were designed for terminal CLIs and single IDEs. We unlocked them for every AI and browser.

        


        

          
          
          

            

              

                
              

              

                
Locked Inside IDEs & CLIs

                
Can't use skills with web AIs

              

            

            
You find an awesome skill on skills.sh, but the only way to run it is by installing it via terminal into Claude Code or Cursor. You can't easily use it with ChatGPT, Claude.ai, or Gemini.

            

            

              

                
              

              

                
1-Click Copy to Any AI

                
Freedom from IDE Silos

              

            

            
Extract any skill into a self-contained prompt with inlined scripts. Copy and paste directly into ChatGPT Custom Instructions, Claude.ai Projects, Gemini, or DeepSeek.

          


          
          

            

              

                
              

              

                
Multi-File Context Bloat

                
Burning 15k+ tokens per prompt

              

            

            
Raw repos have 10+ scattered markdown files and helper scripts that burn valuable context window limits and confuse the model.

            

            

              

                
              

              

                
Deterministic Consolidation

                
Up to 78% Context Savings

              

            

            
Our WASM compiler inlines essential scripts into clean markdown code blocks and compresses references into collapsible sections.

          


          
          

            

              

                
              

              

                
Fragile Terminal Dependencies

                
Node version mismatches & Windows errors

              

            

            
Running npx skills add fails on terminal path quirks, permission errors, and missing Python/Node runtimes on developers' machines.

            

            

              

                
              

              

                
Zero-Install WebAssembly

                
100% In-Browser Sandbox

              

            

            
No dependencies or terminal setup needed. Runs in any modern browser instantly with File System Access and Drag-and-Drop ZIP support.
