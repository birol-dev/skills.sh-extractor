skills.sh is a modern standard for packaging modular AI instructions, prompts, and playbooks. Instead of asking an AI generic questions, a "skill" gives it deep domain knowledge—like expert marketing tactics, copywriting formulas, or code architectures.

skills.sh was originally designed for developers using the command line with npm. But most people who need copywriting, marketing, design, and growth skills aren't developers. We built this tool so anyone can browse, unpack, and copy any skill in 1-click right from their web browser.
