Skill Extractor is a compiler, not an author. It unpacks and reformats agent skills that were researched and written by the people and communities below. The catalog currently ships — curated skills, grouped here by the repository they came from. If you use a skill from this library, credit belongs to its original author — follow the link to their repo.

Spot an attribution error, or are you the author of one of these skills and want changes made? Open an issue on the Skill Extractor GitHub repo ↗.
