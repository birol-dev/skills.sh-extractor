More detail

Tools, repos, offline use and who to credit.

Does this work with Cursor and Antigravity?

Yes. Copy the compiled prompt into Cursor, Windsurf, Antigravity, or GitHub Copilot the same way you would paste it into ChatGPT or Claude. The compiler app can also export markdown for local agent folders.

Can I extract a custom GitHub repo, not just the curated list?

Yes. Open the compiler workstation, paste any public GitHub skill repository URL or npx skills add command, and extract it. The 55+ library is a starting catalog, not a limit.

Does Skill Extractor work offline?

After the page and WASM engine load, curated prompts and IndexedDB playbooks work without a network. Fetching a new GitHub repository still needs connectivity to GitHub.

Who writes the skills in the library?

Skill Extractor is a compiler, not an author. Each curated skill is sourced from a public repository. See Credits & Sources for authors and original repo links.

Is Skill Extractor free?

Yes. It is open source under the MIT license. There is no paid tier and no telemetry backend. The source is on GitHub.

How is this different from running npx skills add?

npx skills add installs a skill through Node.js on your machine. Skill Extractor performs the unpack and compile step in the browser so you can read and copy the playbook without a CLI toolchain. That is the problem we started from.
